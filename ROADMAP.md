# Where useful contributions can make a difference

This is a set of priorities, not promised delivery dates. Start with a small reproducible problem.

## Release foundations

- Finalize and publish the code license, copyright and dependency notices.
- Verify production HTTPS, WebSocket and TURN behavior on real networks.
- Review historical secrets and legacy data before broader promotion.
- Publish reproducible tests and truthful compatibility notes.

## Great first contributions

- Reproduce the first-call flow on a named iPhone, iPad, Pixel or modest Android device.
- Check keyboard focus, screen-reader labels and 320-pixel layouts.
- Improve a confusing setup or backup explanation using synthetic examples.
- Document a measured weak-network failure and what helped.

## Deeper engineering work

- Real TURN failover and capacity testing without silent Direct fallback.
- Independent review of signaling authentication, bounds and invitation handling.
- Recovery from browser suspension and permission changes.
- More efficient weak-network behavior supported by measurements.

## Sustainability, after reliability

Managed hosting, deployment help and enterprise support are possible revenue paths. They require actual operational capacity and contracts before being sold. See COMMERCIAL.md.
