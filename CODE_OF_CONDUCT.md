# Community conduct

Be respectful, specific and constructive. Critique ideas and code without attacking people. Make room for different experience levels, languages and accessibility needs.

Harassment, threats, discrimination, publication of private information and unauthorized testing against others are not acceptable. Keep issues focused on reproducible problems and useful improvements.

For a conduct concern, contact the maintainer through an available private channel. If none is listed, request a private channel without posting sensitive details. Maintainers may remove inappropriate content or restrict participation to protect the community, and should explain moderation decisions where doing so does not expose private information.
