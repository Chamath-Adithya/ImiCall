# Getting help

Start with the README and the website field notes. For a reproducible bug, use the bug report template and include device/browser versions, steps, permission state and expected behavior. Use fresh synthetic connections; never post a full private invitation, contact export, recording or credential.

Questions and ideas can use a GitHub issue. Search existing issues first and keep one topic per issue. No guaranteed support response time is offered.

Security problems belong in a private channel described by SECURITY.md. ImiCall is not an emergency calling service and must not be relied on for emergency communications.
